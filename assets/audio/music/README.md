# Music Loops

Place curated, royalty-safe background loops here:

- `ambient-01.mp3`
- `tech-house-01.mp3`

Guidelines:

- instrumental only, no vocals;
- calm/meditative;
- 30-180 seconds works well;
- seamless loop preferred;
- licensed for product/commercial use.

If a file is missing, the Playground temporarily falls back to procedural background audio.
